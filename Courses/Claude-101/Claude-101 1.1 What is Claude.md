# 1.1 What is Claude?

**Captured:** 2026-09-14 · **Est. time:** 15 min

Course: [[Claude-101]]

## Summary

Claude is built to be helpful, harmless and honest, trained with Constitutional AI against an explicit set of principles. The course frames it as a thinking partner that works a problem with you, not a search box that retrieves facts. It covers five capability areas (writing, research and analysis, coding, problem-solving, learning), with a 200K+ token context window and up to 1M on paid plans with supported models. Claude is on every plan and reachable through Claude.ai, Claude Code, Claude Tag in Slack, Claude Design and Claude for Microsoft 365.

## Objectives

- Explain what Claude is and the design principles behind it
- Describe core capabilities and how it differs from a simple chatbot

## Written

### Core takeaways

**Design principles — helpful, harmless, honest.** Claude is trained under an approach Anthropic calls *Constitutional AI*: the model is aligned against an explicit set of principles rather than tuned purely on human preference labels. Practical effect — it avoids toxic or discriminatory output, declines to assist illegal or unethical activity, and is meant to operate transparently.

**Not a chatbot.** The framing the course pushes is *thinking partner*, not answer machine. The distinction that matters: a search box retrieves a fact; Claude works a problem with you — summarization, research synthesis, collaborative writing, Q&A, coding, reasoning through ambiguity.

**Steerable.** Tone, personality, and behavior all take direction. Less prompt-wrestling to land the output you actually wanted.

**Available on every plan tier** — Free, Pro, Max, Team, Enterprise. Conversations, projects, memory, and preferences sync across devices when signed in.

### Capability areas

| Area | What it covers |
|---|---|
| Writing & content | Emails, posts, reports; iterate on structure/tone until it sounds like you |
| Research & analysis | Upload docs, synthesize findings. Context window 200K+ tokens (~500 pages); up to 1M tokens on Pro/Max/Team/Enterprise with supported models |
| Coding | Write, debug, explain across languages — one of its strongest areas |
| Problem-solving | Math, strategy, analysis. **Thinking** = optional step-by-step reasoning before answering |
| Learning | **Learning mode** guides your reasoning instead of handing over answers |

### Access surfaces

| Surface | Use it for |
|---|---|
| **Claude.ai** (web/desktop/mobile) | Primary interface — conversation, writing, research, file creation. Main focus of this course |
| **Claude Code** | Agentic coding tool. Edits files directly, runs commands, creates commits. Built for devs but usable for general desktop file manipulation |
| **Claude Tag** (Slack) | Chat from the AI assistant header or by tagging Claude in threads; searches channels, DMs, and shared files for context |
| **Claude Design** | Turn a description, sketch, or screenshot into an interactive prototype you can refine and hand off |
| **Claude for Microsoft 365** | Sidebar in Excel, PowerPoint, Word, Outlook — carries context between apps |
